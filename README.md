# School Students Data Analysis

## 📌 Project Overview

This project analyzes school student data using Python, Pandas, NumPy, Matplotlib, and Seaborn.

The notebook focuses on understanding the dataset, checking data quality, cleaning the data, generating descriptive statistics, and exploring patterns through visualizations.

## 📊 Dataset

- **Records:** 900
- **Columns:** 17
- **Domain:** School / Student Data
- **Main file:** `school_students_analysis.ipynb`

The analysis includes checks for missing values and duplicate records, followed by data cleaning and exploratory analysis.

## 🧹 Data Cleaning & Preparation

The notebook covers:

- Dataset inspection
- Data types and structure checks
- Missing-value analysis
- Duplicate-record checks
- Descriptive statistics
- Data cleaning
- Export of the cleaned dataset as `cleaned_school_data.csv`

## 📈 Exploratory Data Analysis

The notebook uses Pandas and visualization libraries to explore the student dataset and identify useful patterns.

Visual analysis is performed with:

- Matplotlib
- Seaborn

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/School-Students-Data-Analysis.git
cd School-Students-Data-Analysis
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Open the notebook

```bash
jupyter notebook school_students_analysis.ipynb
```

You can also open the `.ipynb` file directly through GitHub or Jupyter/VS Code.

## 🎯 Project Objective

The objective of this project is to practice a complete beginner-to-intermediate data analysis workflow:

**Raw Data → Data Understanding → Data Cleaning → Statistical Analysis → Visualization → Insights**
